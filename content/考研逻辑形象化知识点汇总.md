# 考研逻辑 · 形象化知识点全汇总

> **总览**：管综逻辑共30题，60分，建议用时50-55分钟。三大板块好比一座"逻辑城堡"——
> - 🏰 **形式逻辑** = 城堡的**地基与梁柱**（公式硬规则，约8-10题）
> - 🕵️ **论证逻辑** = 城堡里的**侦探游戏**（找漏洞、补缺口，约12-14题）
> - 🧩 **综合推理** = 城堡的**密室逃脱**（信息拼图，约8-10题）

## 第一篇 🏰 形式逻辑——"公式王国"

> **核心心法**：形式逻辑不讲"道理"，只讲"规则"。就像数学公式，背下来直接套，别想太多！

### 一、直言命题（性质命题）——"四个骑士的爱恨情仇"

**四种基本命题**（用A、E、I、O四个骑士来记）：

| 代号 | 命题形式 | 口诀 | 形象比喻 |
|------|----------|------|----------|
| **A** | 所有S都是P（全称肯定） | **全肯A** | 全班都是学霸 |
| **E** | 所有S都不是P（全称否定） | **全否E** | 全班都不是学霸 |
| **I** | 有的S是P（特称肯定） | **特肯I** | 班里有学霸 |
| **O** | 有的S不是P（特称否定） | **特否O** | 班里有学渣 |

**对当关系方阵**（"四角恋爱图"）：

```
        A（全肯） ———— 反对关系 ———— E（全否）
       /    \                           /    \
      /      \                         /      \
  差等      矛盾                   矛盾      差等
     \        \                   /         /
      \        \                 /         /
        I（特肯） —— 下反对关系 —— O（特否）
```

**四大关系速记口诀**：
- 🎯 **矛盾关系**（A↔O、E↔I）：**一真一假，死对头**
  - "所有人都及格" vs "有人没及格" → 必有一对一错
- ⚔️ **反对关系**（A↔E）：**至少一假，不同真**
  - "全班都及格"和"全班都不及格" → 不可能同时对，但可能同时错
- 🤝 **下反对关系**（I↔O）：**至少一真，不同假**
  - "有人及格"和"有人没及格" → 不可能同时错，但可能同时对
- 📐 **差等关系**（A→I、E→O）：**上真下必真，下假上必假**
  - 全班都及格 → 肯定有人及格
  - 没人及格 → 全班都没及格

### 二、联言命题 & 选言命题——"并联电路 vs 串联电路"

#### 1. 联言命题（且）——"串联灯泡"
- **逻辑式**：p ∧ q（p且q）
- **标志词**：并且、而且、既…又…、虽然…但是…、不但…而且…
- **真假规则**：**全真才真，一假就假**（像串联电路，一个断了全不亮）
- **矛盾**：非p 或 非q（¬p ∨ ¬q）

#### 2. 选言命题（或）——"并联灯泡"

**相容选言**（或者…或者…）：
- **逻辑式**：p ∨ q
- **标志词**：或者…或者…、至少有一个
- **真假规则**：**一真就真，全假才假**（像并联电路，亮一个就行）
- **推理规则**：**否定肯定式** —— 否定一个，肯定另一个
  - p∨q 为真 + p为假 → q必为真
  - ⚠️ 肯定一个不能否定另一个（可能两个都真）
- **矛盾**：非p 且 非q（¬p ∧ ¬q）

**不相容选言**（要么…要么…）：
- **逻辑式**：p ⊕ q（二者必居其一）
- **标志词**：要么…要么…、二者不可兼得
- **真假规则**：**一真一假才为真**（只能选一个）
- **推理规则**：否定肯定式 + 肯定否定式（两种都行）
- **矛盾**：(p且q) 或 (非p且非q)

> 💡 **德摩根定律**（"拆括号法则"）：
> - ¬(p ∧ q) = ¬p ∨ ¬q → **"且"变"或"，两边都否定**
> - ¬(p ∨ q) = ¬p ∧ ¬q → **"或"变"且"，两边都否定**
> 
> 记忆口诀：**去括号，且或互换，各加非**

### 三、假言命题——"因果传送带"（重中之重！）

> **地位**：形式逻辑的绝对核心，每年必考5-7题，也是综合推理的基础工具。

#### 1. 充分条件（前推后）——"足够了"
- **逻辑式**：A → B
- **标志词**：如果…那么…、只要…就…、若…则…、一…就…、所有…都…、…一定…
- **含义**：有A就够了，A足以导致B
- **口诀**：**充分条件前推后**

#### 2. 必要条件（后推前）——"不能少"
- **逻辑式**：B → A（即 A ← B）
- **标志词**：只有…才…、…是…的前提/基础/必要条件/不可或缺、不…不…、除非…才…
- **含义**：没A就不行，A是B的必需品
- **口诀**：**必要条件后推前**

#### 3. 充要条件（两头推）——"等价交换"
- **逻辑式**：A ↔ B
- **标志词**：当且仅当、唯一条件
- **口诀**：**充要条件两头推**

#### 4. 假言命题的"四大法宝"

**法宝一：逆否等价**（最核心！）
- A → B 等价于 ¬B → ¬A
- **口诀**：**肯前必肯后，否后必否前；否前肯后不一定**
- 形象理解："下雨→地湿" ≠ "地湿→下雨"（地湿可能是洒水车）

**法宝二：传递性**
- A→B，B→C → A→C
- 像多米诺骨牌，推倒第一个，最后一个必倒

**法宝三：假言的矛盾**（"假言求假，前真后假"）
- ¬(A→B) = A ∧ ¬B
- 只有一种情况能推翻"如果A那么B"——**A发生了，但B没发生**
- 记忆：承诺"考上就请客"，什么时候算食言？**考上了但没请客**

**法宝四：假言与选言的转换**
- A → B 等价于 ¬A ∨ B
- 口诀：**前件加非变或**
- "下雨就带伞" = "不下雨 或 带伞"

#### 5. "除非…否则…"翻译法（高频易错点）
- **口诀**：**去"除"去"否"，箭头右划**
- 除非A，否则B → ¬A → B
- 例：除非努力，否则失败 → 不努力 → 失败
- 变形：B，除非A → ¬A → B（一样的）

### 四、模态命题——"可能性的温度计"

**四个模态词**：
| 必然P（□P） | 必然非P（□¬P） |
|:---:|:---:|
| 可能P（◇P） | 可能非P（◇¬P） |

**模态对当关系**：和直言命题完全一样的结构！
- 矛盾：必然P ↔ 可能非P；必然非P ↔ 可能P
- 反对：必然P ↔ 必然非P（至少一假）
- 下反对：可能P ↔ 可能非P（至少一真）

**模态否定转换口诀**：**"不"字进门，必然变可能，肯定变否定**
- 不必然 = 可能不
- 不可能 = 必然不
- 形象：把"不"扔进模态方阵里，"必然"和"可能"互换位置，"是"和"非"互换

### 五、三段论——"三句话的接力赛"

**结构**：大前提 + 小前提 → 结论
- 大项（P）：结论的谓项
- 小项（S）：结论的主项
- 中项（M）：两个前提都有，结论里没有的"媒人"

**七条规则速记**（用"周延"概念）：
1. **一个三段论只有三个概念**（不能"四概念"）
2. **中项至少周延一次**（媒人至少得露一次全脸）
3. **前提中不周延的，结论中也不能周延**（不能"扩大范围"）
4. **两个否定前提推不出结论**
5. **前提一否，结论必否；结论否，前提必有一否**
6. **两个特称前提推不出结论**
7. **前提一特，结论必特**

> 🎯 **快速解题法**：
> - 找结论 → 确定S和P → 找中项M → 看周延 → 排除选项
> - 结构相似题：**标字母法**——把每个概念用字母代替，看推理形式是否完全一致

## 第二篇 🕵️ 论证逻辑——"侦探破案游戏"

> **核心心法**：论证逻辑就是"找漏洞"和"补漏洞"的游戏。
> 题干 = 案发现场，选项 = 嫌疑人，你 = 侦探。
> 
> **标准动作**：先找论点 → 再找论据 → 分析论证方式 → 看选项如何"动手"

### 一、论证结构三件套

```
论据（前提） ———【论证方式】——→ 论点（结论）
    📎                         🎯
  证据/原因                  观点/结果
```

**找论点技巧**：
- 看首尾句（80%在结尾）
- 找标志词：因此、所以、由此可见、据此认为、这说明、专家认为
- 找结论性陈述（不是事实陈述，是观点陈述）

### 二、六大题型全解

#### 题型1：削弱题——"拆台专家"
> **目标**：让论证站不住脚

**削弱力度排行**（从强到弱）：
1. 🥇 **否定论点**：直接说结论不对（最狠，但考得少）
2. 🥈 **因果倒置**：不是A导致B，是B导致A（针对因果论证，极狠）
3. 🥉 **拆桥/切断联系**：论据和论点没关系（"你说的A和我说的B不是一回事"）
4. **另有他因**：导致结果的不是A，是C
5. **否定论据**：你的证据不对/不成立
6. **举反例**：有个情况不符合
7. **样本问题**：以偏概全、样本不具代表性

**常见削弱模型**：
| 论证模型 | 削弱套路 | 形象比喻 |
|----------|----------|----------|
| 因果论证（A→B） | 因果倒置、他因、无因有果、有因无果 | 你以为是凶手，其实是受害者 |
| 类比论证 | 指出本质不同 | 人和老鼠不一样 |
| 统计论证 | 样本不具代表性、数据有问题 | 只调查富人说大家都有钱 |
| 措施目的 | 措施不可行/达不到目的/有副作用 | 吃药病没好还伤胃 |
| 比例论证 | 用绝对数代替比例 | 考100分的人多=简单？要看总人数 |

#### 题型2：加强/支持题——"助攻队友"
> **目标**：让论证更站得住脚

**加强方式排行**：
1. 🥇 **搭桥**：建立论据和论点的联系（最常考）
2. 🥈 **排除他因**：不是别的原因导致的
3. 🥉 **补充论据**：增加新证据支持结论
4. **重申论点**：换个说法再说一遍（弱）

**加强模型对应**：
| 论证模型 | 加强套路 |
|----------|----------|
| 因果论证 | 无因无果（没A就没B）、排除他因 |
| 类比论证 | 指出本质相同 |
| 统计论证 | 样本具有代表性 |
| 措施目的 | 措施可行、能达到目的、无副作用 |

#### 题型3：假设题——"找隐形桥梁"
> **目标**：找出论证中"默认成立但没说出来"的前提

**核心方法**：
- **搭桥法**：论据和论点之间有跳跃，把跳跃的地方连上
- **取非法**（验证假设）：把选项否定后代入，如果论证崩了，那它就是必要假设
  - 口诀：**假设取非，论证崩溃**

> 💡 假设 vs 加强的区别：
> - 假设是"没它不行"（必要条件）
> - 加强是"有它更好"（充分条件）
> - 假设一定能加强，但加强不一定是假设

#### 题型4：解释题——"和事佬"
> **目标**：解释看似矛盾的两个现象为什么能共存

**解题关键**：找一个"第三者"把矛盾双方都解释通
- 常见套路：另有他因、标准不同、角度不同、时间差

#### 题型5：结论题——"推理小能手"
> **目标**：从题干信息推出必然结论

**解题原则**：
- **忠于原文**：只能用题干给的信息，不能加自己的知识
- **从弱原则**：选项说"可能""有些"的，对的概率大；说"必然""所有"的，要小心
- **排除法**：排除无中生有、过度推断、偷换概念的选项

#### 题型6：评价题——"裁判"
> **目标**：评价论证是否有效，或找出论证的漏洞/方法

**常见考法**：
- 指出论证方法（归纳、演绎、类比、归谬等）
- 指出逻辑漏洞（偷换概念、以偏概全、循环论证、诉诸权威等）
- 评价论证有效性（找一个关键问题，回答"是"或"否"能分别加强/削弱）

### 三、论证逻辑"十大常见陷阱"

| 陷阱类型 | 特征 | 避坑方法 |
|----------|------|----------|
| 🔴 偷换概念 | 论据和论点的关键词不是一个意思 | 圈出核心概念，比对是否一致 |
| 🔴 以偏概全 | 用部分推整体 | 看样本是否有代表性 |
| 🔴 因果倒置 | 把原因和结果搞反了 | 注意时间先后、谁依赖谁 |
| 🔴 诉诸权威 | "某某专家说的" | 专家说的不一定对 |
| 🔴 诉诸众人 | "大家都这么认为" | 多数不等于正确 |
| 🔴 无关选项 | 话题跑偏了 | 紧扣论点关键词 |
| 🔴 不明确选项 | "可能""尚不清楚""有待研究" | 这类一般不选（削弱/加强题） |
| 🔴 对策类选项 | "应该…""应当…" | 论证题一般不选对策 |
| 🔴 类比不当 | 本质不同的事物硬比 | 找本质差异 |
| 🔴 数字陷阱 | 绝对数vs比例、平均数vs个体 | 看清数字的含义 |

## 第三篇 🧩 综合推理——"密室逃脱"

> **核心心法**：综合推理不是考"逻辑知识"，是考"信息处理能力"。
> 就像拼图——先找边角（确定信息），再拼边框（最大信息），最后填中间。
> 
> **黄金法则**：**从确定信息入手，从最大信息突破**

### 一、常见题型分类

| 题型 | 特征 | 核心方法 |
|------|------|----------|
| **排序题** | 谁在谁前面/后面 | 画数轴、列不等式 |
| **匹配/对应题** | 谁是什么身份/职业/国籍 | 画表格（二维表） |
| **分组题** | 谁和谁一组 | 列表格、看限制条件 |
| **真话假话题** | 有人说真话有人说假话 | 找矛盾、找反对、假设法 |
| **数字推理题** | 涉及数量、比例、计算 | 列方程、画韦恩图 |

### 二、五大解题神器

#### 神器一：表格法（最常用）
- **适用**：匹配题、对应题、分组题
- **做法**：行和列分别放两类元素，已知条件打√打×
- **技巧**：每推一个结论就更新表格，逐步排除

#### 神器二：排序法
- **适用**：排序题、位置题
- **做法**：画一条线（数轴），把元素放上去
- **技巧**：先放确定位置的，再放有相对位置的

#### 神器三：假设法（"试错法"）
- **适用**：真假话、信息不足的题
- **做法**：假设某个条件成立，看能不能推出矛盾
- **技巧**：从出现次数最多的元素开始假设（最快出结果）

#### 神器四：代入排除法
- **适用**：选项信息充分的题
- **做法**：把选项往题干里代，看哪个符合所有条件
- **技巧**：先代最可能的，或者从限制最多的条件开始排除

#### 神器五：画图法
- **适用**：位置关系、集合关系、网络关系
- **做法**：韦恩图（集合）、位置图（空间）、关系图（网络）

### 三、真话假话题——"谁在说谎"

**解题三步走**：
1. **找矛盾**：矛盾关系必一真一假（最快锁定）
2. **找反对**：上反对至少一假，下反对至少一真
3. **假设法**：以上都不行，就假设某人为真/假，推矛盾

> 💡 **多真多假题技巧**：
> - 先找矛盾对（确定一真一假）
> - 剩下的用假设法或继续找关系
> - 注意"两真两假"题：必有一对矛盾 + 一对其他关系

### 四、综合推理提速技巧

1. **先看问什么**：带着问题读题干，抓关键信息
2. **标记确定条件**：用不同符号标注（确定的、可能的、排除的）
3. **善用选项**：选项信息全的直接代入，别傻推
4. **学会放弃**：一道题超过3分钟还没思路，先跳过
5. **同类题打包做**：同一个题干的多道小题一起做，信息可以复用

## 第五篇 🎯 应试策略与时间管理

### 一、做题顺序建议

```
第1步：快速浏览30题，标记题型
       ↓
第2步：先做形式逻辑（公式题，稳拿分，约15分钟）
       ↓
第3步：再做论证逻辑（理解题，注意陷阱，约20分钟）
       ↓
第4步：最后做综合推理（费时间，挑简单的先做，约20分钟）
```

### 二、各题型时间分配

| 板块 | 题量 | 建议时间 | 目标正确率 |
|------|------|----------|-----------|
| 形式逻辑 | 8-10题 | 12-15分钟 | 90%+ |
| 论证逻辑 | 12-14题 | 20-25分钟 | 80%+ |
| 综合推理 | 8-10题 | 18-22分钟 | 70%+ |
| **总计** | **30题** | **50-60分钟** | **80%左右** |

### 三、考场救命技巧

1. **形式逻辑别想太多**：套公式就行，想多了反而错
2. **论证逻辑抓关键词**：论点的核心词是什么，选项必须沾边
3. **综合推理别死磕**：3分钟没思路立刻跳过，有时间再回来
4. **排除法是万能的**：不确定的题，先排除明显错的，再蒙
5. **相信第一感觉**：改答案改错的概率 > 改对的概率
6. **注意"除了哪项"**：看清楚题目问的是"能削弱"还是"不能削弱"
