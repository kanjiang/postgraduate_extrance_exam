# 浙大工程管理在职研备考站 — 设计规格

**日期：** 2026-07-31  
**状态：** 待用户确认  
**一期范围：** 知识点笔记库（预置骨架 + 个人增改 + 多端同步）

---

## 1. 背景与目标

用户正在备考浙江大学工程管理在职研究生，目前已开始学习三门科目：**逻辑、数学、英语二**。需要一个可部署、手机可访问的个人备考网页，用于记录与整理知识点；后续再扩展刷题与进度看板。

### 成功标准（一期）

1. 邮箱注册/登录后，电脑与手机数据一致  
2. 可按三科浏览预置章节与知识点骨架  
3. 可新建/编辑/删除个人知识点（Markdown）  
4. 可搜索、收藏、标记掌握度（未学 / 模糊 / 掌握）  
5. 界面为「日间课桌」风格，科目页为左侧章节树（手机为抽屉）

---

## 2. 分期

| 阶段 | 内容 | 本期 |
|------|------|------|
| 一期 | 登录、三科知识点骨架、CRUD、搜索、掌握度、收藏、响应式 | ✅ |
| 二期 | 题库练习、错题本 | ❌ 不做 |
| 三期 | 学习计划、打卡、进度看板 | ❌ 不做 |

---

## 3. 技术方案

**选定：Next.js + Supabase + Vercel**

| 层 | 选择 | 说明 |
|----|------|------|
| 前端 | Next.js（App Router）+ TypeScript | SSR/静态均可，部署简单 |
| 认证 | Supabase Auth | 邮箱 + 密码 |
| 数据 | Supabase Postgres | 多端同步 |
| 部署 | Vercel | 与 Next.js 配套；需配置环境变量 |

备选（已否决）：Firebase（国内访问偶发不稳）；自建 Node 后端（过重）。

---

## 4. 信息架构与页面

### 4.1 页面

| 路由（示意） | 作用 |
|--------------|------|
| `/login` `/register` | 邮箱密码登录/注册 |
| `/` | 首页：品牌 + 三科入口 + 最近复习/收藏 |
| `/subjects/[slug]` | 科目页：左侧章节树 + 右侧知识点列表/详情区 |
| `/points/[id]` | 知识点详情（亦可在科目页内嵌） |
| `/points/new` `/points/[id]/edit` | 新建/编辑（Markdown） |
| `/search` | 跨科目搜索 |

### 4.2 导航与布局

- **视觉方向：** B · 日间课桌 — 浅灰绿底、森绿强调、清晰无衬；首页品牌「工程管理备考」为一级视觉信号  
- **科目页布局：** A · 左侧章节树；桌面双栏；手机章节树收入抽屉/底部入口  
- **手机优先**，桌面加宽阅读区

### 4.3 交互

- 知识点正文 Markdown 渲染  
- 掌握度一键三态：未学 / 模糊 / 掌握  
- 收藏开关  
- 首页展示最近复习与收藏快捷入口

## 5. 数据模型

### 5.1 策略：系统骨架 + 用户覆盖层

- 系统维护只读模板：`subjects`、`chapters`、`knowledge_points`（`is_template = true` 或无 `user_id`）  
- 用户增改写入个人层，关联 `auth.users.id`  
- 升级官方骨架时不覆盖用户正文与掌握度  

### 5.2 表（一期）

**subjects**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | PK |
| slug | text | `logic` / `math` / `english2` |
| name | text | 逻辑 / 数学 / 英语二 |
| sort_order | int | 排序 |

**chapters**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | PK |
| subject_id | uuid | FK |
| parent_id | uuid? | 可选多级 |
| title | text | 章节名 |
| sort_order | int | |
| user_id | uuid? | null = 系统；有值 = 用户自建 |

**knowledge_points**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | PK |
| chapter_id | uuid | FK |
| title | text | |
| body_md | text | Markdown 正文 |
| sort_order | int | |
| user_id | uuid? | null = 系统模板；有值 = 用户自建 |
| source_template_id | uuid? | 若从模板派生/覆盖，指向模板 id |

**user_point_state**（用户对任意知识点的学习状态）

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | uuid | PK 部分 |
| knowledge_point_id | uuid | PK 部分 |
| mastery | enum | `unlearned` / `fuzzy` / `mastered` |
| starred | bool | 收藏 |
| body_override_md | text? | 用户改写的正文；null 则显示模板正文 |
| title_override | text? | 可选标题覆盖 |
| updated_at | timestamptz | 用于「最近复习」 |

### 5.3 权限（RLS）

- 模板行：所有登录用户可读，不可写  
- 用户自建章节/知识点、以及 `user_point_state`：仅本人读写

## 6. 预置骨架内容（一期）

一期先给**目录 + 简要要点**，用户再细化。章节可按考纲微调，但科目固定为三科。

### 逻辑

1. 形式逻辑（假言、选言、联言、直言、模态等）  
2. 论证评价  
3. 削弱 / 加强  
4. 假设  
5. 归纳与类比  
6. 其他常考题型（解释、评价、对话等）按需归入  

### 数学

1. 算术  
2. 代数  
3. 几何  
4. 数据分析（统计初步等，按考试大纲收束）  

### 英语二

1. 词汇与语法基础  
2. 阅读理解  
3. 完形填空  
4. 英译汉  
5. 写作（小作文 / 大作文）  

种子数据以 SQL migration / seed 脚本写入；用户首次登录即可浏览。

---

## 7. 非目标（一期明确不做）

- 刷题、错题本、计时模考  
- 打卡、学习计划、统计看板  
- 手机号验证码、微信登录  
- 离线 PWA（可后续再加）  
- 多人协作 / 分享公开笔记  

---

## 8. 部署与配置

1. 创建 Supabase 项目，执行 schema + seed + RLS  
2. 本地/生产环境变量：`NEXT_PUBLIC_SUPABASE_URL`、`NEXT_PUBLIC_SUPABASE_ANON_KEY`（及如需的 service role 仅服务端）  
3. Vercel 绑定仓库并配置相同环境变量  
4. 开启邮箱确认策略按用户偏好（一期建议：开发期可关闭强制确认，生产再开）  

---

## 9. 风险与缓解

| 风险 | 缓解 |
|------|------|
| 国内访问 Vercel/Supabase 偶发慢 | 一期接受；若严重再评估国内托管 |
| 模板升级与用户覆盖冲突 | 覆盖层字段明确；合并时优先用户 override |
| Markdown 编辑体验 | 一期用可靠基础编辑器 + 预览；不追求重度 IDE |
